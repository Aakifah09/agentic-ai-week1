# BITS Pilani Dubai — Agentic AI Engineering (CRP 2026)

Course code for the **Agentic AI Engineering** track, run by Tecoholic with
BITS Pilani Dubai Campus. Each week has its own folder with two parallel tracks:

- **`skeleton/`** — starter code with `TODO`s. **This is where you work.**
- **`trainer/`** — full reference solutions. Peek only if you're stuck.

## Getting started

1. Read **[Week 1/STUDENT_ACTION_ITEMS.md](./Week%201/STUDENT_ACTION_ITEMS.md)**
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set your Groq API key in `.env`:
   ```bash
   GROQ_API_KEY=your_key_here
   ```
4. Run setup check:
   ```bash
   python "Week 1/skeleton/00_setup_check.py"
   ```
